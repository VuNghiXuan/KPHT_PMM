# VnxChatBot Architecture v1.0

## 1. Flow chính: Xử lý kiến thức
Người dùng (Upload File) -> `apps.group_chat.Document` -> `signals.py` -> `apps.ai_assistant.RAGEngine` -> VectorStore -> KnowledgeUnit.

## 2. Nguyên tắc Tenant Isolation
Mọi dữ liệu (GroupAIProvider, Membership, Document, Subscription) đều phải có `group_id` hoặc `ForeignKey` đến `ChatGroup`.

## 3. Quản lý AI
- Ollama: Mặc định (Local).
- Cloud Providers (Groq/Gemini): Tự nhập key (Group-Centric).
