BẢN THIẾT KẾ CHI TIẾT TỪNG GIAI ĐOẠN📍 Giai đoạn 1: Dựng móng & Tách rời Kiến trúc (Đang thực hiện)Mục tiêu: Dùng Gemini (Chat/API miễn phí) để dựng sẵn phần "khung xương" vững chắc, sẵn sàng để AI sau này chỉ việc đọc code và mở rộng.Tách biệt Core Backend & UI (Decoupled Architecture):Backend (Django/Python): Cung cấp các RESTful APIs & WebSockets tiêu chuẩn cho chat, truy vấn tri thức, và thực thi code.UI Dashboard: Tối ưu Master-Detail Dashboard để quản lý tri thức, hiển thị bảng biểu, công thức.UI Chat (Widget): Đóng gói ô chat thành một file JS nhẹ (sử dụng Shadow DOM hoặc Iframe) để có thể nhúng vào bất kỳ website nào bằng một dòng mã <script>.Cơ chế Interactive Knowledge Completion (AI Tự Hỏi Admin):Khi upload tài liệu thô (Word, PDF, Bảng giá), backend phân tích nếu thấy thiếu công thức hoặc mơ hồ sẽ tạo cảnh báo trên Dashboard để Admin bổ sung.📍 Giai đoạn 2: Thiết lập Trạm Vibe Coding Local (Không tốn chi phí AI ngoài)Mục tiêu: Vũ không cần tự viết lại một công cụ Vibe Code từ đầu. Chúng ta tận dụng các framework mã nguồn mở đỉnh cao có sẵn trên VS Code và kết nối trực tiếp với Ollama chạy dưới máy local của Vũ.Cấu hình Công cụ Vibe Coding Local:Công cụ cài trên VS Code: Sử dụng Roo Code (Roo Cline) hoặc Aider hoặc Continue.dev (đều là các công cụ Vibe Coding hàng đầu hoàn toàn miễn phí).Backend LLM: Kết nối các extension này tới Ollama đang chạy trên máy tính với mô hình Qwen 2.5 Coder (7B/14B) — mô hình lập trình local mạnh nhất hiện nay.Luồng làm việc chuẩn Vibe Coding:Bước 1 (Prompt): Vũ gõ yêu cầu tính năng trên VS Code (VD: "Tạo cho tao API bóc tách công thức toán từ file PDF và tự sinh hàm Python").Bước 2 (Planning): Qwen 2.5 (Ollama) sẽ đọc toàn bộ cấu trúc thư mục dự án Django, đưa ra Kế hoạch từng bước (Execution Plan) và liệt kê các file cần sửa.Bước 3 (Approval): Vũ bấm Approve (Duyệt) trên giao diện.Bước 4 (Auto Code & Diff View): Ollama tự động sửa code trực tiếp trên VS Code, hiển thị bảng so sánh Side-by-Side (Diff View). Vũ kiểm tra xem đúng ý chưa rồi bấm Accept.📍 Giai đoạn 3: Hệ thống Tự Tiến Hóa & Vận Hành Độc LậpMục tiêu: Bàn giao toàn bộ việc phát triển dự án cho "Đội ngũ AI Local" và triển khai cho khách hàng.Dynamic Tool Registry & Code Sandbox:Khi Admin gõ quy tắc nghiệp vụ bằng tiếng Việt tự nhiên (VD: "Thu đổi vàng 610 trừ 2% hao hụt và trừ voucher"), AI Local (Ollama) tự dịch thành hàm Python.Hàm này được lưu vào Dynamic Tool Registry và chạy trong một Secure Sandbox (Restricted Python/Docker) cách ly tuyệt đối, đảm bảo an toàn hệ thống.Agentic Multi-Agent Orchestration:Supervisor Agent: Phân loại câu hỏi của người dùng.RAG Agent: Tra cứu điều khoản chính sách (GraphRAG + Vector DB).Math/Code Agent: Gọi các hàm Python trong Sandbox để tính toán con số chính xác 100%.Response Synthesizer: Tổng hợp câu trả lời kèm link trích dẫn điều khoản/công thức.IV.
