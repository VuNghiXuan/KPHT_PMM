VnxChatBot Architecture Dashboard (Living Documentation)

Hệ thống tự động đồng bộ hóa kiến trúc Modular Monolith và kiểm soát vòng đời tri thức (Knowledge Lifecycle).

1. Sơ đồ Luồng (Code Flow)
2. Sơ đồ ERD (Tự động quét Models)
3. Sơ đồ Trạng thái (Knowledge State)
4. Sơ đồ Phân hệ (Components)

Mô hình thực thể mối quan hệ (Group-Centric ERD)

erDiagram ChatGroup ||--o{ Membership : contains ChatGroup ||--o{ Document : uploads ChatGroup ||--o{ KnowledgeUnit : owns ChatGroup ||--o{ Subscription : has ChatGroup ||--o{ GroupAIProvider : configures Document ||--o{ KnowledgeUnit : extracts ChatGroup { int id PK string name datetime created_at } Membership { int id PK int user_id FK int group_id FK boolean is_ai string role } Document { int id PK int group_id FK string file_path } KnowledgeUnit { int id PK int document_id FK int group_id FK string status }
